# Antigravity++ 0.1.1 便携版

完整应用包从 [GitHub Releases](https://github.com/shallFun4Learning/AntigravityPlusPlus/releases) 下载，按系统与处理器选择对应 ZIP。主线自动构建会标记为预览版；每次发布附带 `SHA256SUMS.txt`，可校验下载文件完整性。

Windows：完整解压发布包，运行 AntigravityPlusPlus.exe。保留同目录 antigravity-node.exe 和 backend 文件夹。无需自行安装 Node.js 或 Rust，外壳需要系统 WebView2 Runtime。

macOS（Beta）：下载 Apple Silicon 或 Intel 对应的 ZIP，解压后打开 Antigravity++.app。未经过 Apple 公证。升级时替换整个应用，保留系统中的用户数据目录。

## 使用与退出

在工作台选择桌面版或 IDE 版，按需设置本地代理端口，再点击启动。未检测到客户端时仍可查看设置。若已安装到其他位置，点击“配置启动路径”手动指定。客户端运行时，点击重启按钮可打开确认窗口，请先保存工作。

关闭窗口后继续驻留 Windows 托盘或 macOS 顶部菜单栏。macOS 窗口隐藏时同时隐藏 Dock 图标；菜单中的“显示窗口”可以重新打开。彻底退出请在托盘或菜单栏选择“退出应用”。Antigravity++ 退出不会强制关闭其他 Antigravity 进程。

IDE 支持启动、代理配置和上下文、模型用量圆环，可查看当前会话占用、采样模型、速度、额度窗口与重置时间；界面汉化仍仅用于桌面版。

## 多账号管理

首次使用需阅读风险提示并主动勾选确认，确认状态保存在本机，后续不再重复提示。账号管理可能触发 Google 风控，请遵守当地法律法规、Google 服务条款和 Antigravity 使用政策。

- “导入当前登录”读取所选客户端已有的本地凭据，不会退出正在运行的 Antigravity。
- “添加账号”生成网页登录链接，支持打开或复制。授权后本地回调会自动保存账号。
- 未自动保存时，可在手工回填中粘贴登录成功后的完整链接，再点击“回填登录结果”。
- 在账号列表中选中账号，点击“切换并重启”并确认后，会退出对应客户端、更新凭据并自动重启。请先保存未完成的工作。

桌面版和 IDE 版分别保存当前账号选择。账号索引、加密凭据及其本地密钥均位于应用数据目录，请勿将这些文件上传到公开问题或代码仓库。

## 额度圆环

在工作台或“界面增强”中，分别开启“AG 内上下文”和“AG 内模型用量”。通过启动器运行客户端后，可在输入区点击上下文圆环查看最近一次请求的上下文占用，或点击额度圆环查看剩余比例和重置时间。只开模型用量时，新建对话也能查看额度。

真实耗尽显示 0%；未知、禁用和接口不可用分别显示，不会用虚构百分比代替。

## 用户数据与更新

用户数据由外壳存放在系统应用数据目录，包含设置、账号库、运行日志、词典补丁和后台/UI 热更新。升级完整包不需要删除这些配置。

Windows / macOS 用户可在侧栏点击“检查更新”获取兼容的后台与界面资源，完成后从托盘或菜单栏退出 Antigravity++，再重新打开。

热更新无法替换原生外壳。本次涉及原生窗口及内置运行时调整，从旧包升级时请下载完整包。检查更新按钮无法使用时，也请使用完整包升级。

日志可能包含本地路径，对外分享前请检查内容。
